✨ Overview

The platform showcases:

🎸 Courses

🎤 Instructors

📩 Contact Page

🎨 Advanced UI animations

⚡ Optimized performance with static generation

It focuses on clean UI, smooth animations, and responsive design.

⚙️ Installation

Clone the repository
and here's the live link : https://next-js-music-webpage.vercel.app/courses 


Move into project folder:

cd music-app


Install dependencies:

npm install


Run development server:

npm run dev


Build for production:

npm run build


Start production server:

npm run start

🚀 Deployment

This project is optimized for deployment on Vercel.

Steps:

Push code to GitHub

Import project into Vercel

Click Deploy

Done 🎉
